core_claim=Exact-inversion diffusion samplers can be written as bidirectional explicit variable-stepsize linear multistep methods, and the optimized 2-step O-BELM recurrence achieves a higher-order local truncation error than DDIM, EDICT, and BDIA while remaining explicit and training-free.
assumptions=The sampler follows a diffusion ODE discretized on a monotone noise grid; the current state, the immediately previous state, the current model derivative, and consecutive step sizes are available; the update may reuse already-computed history but may not query the model at extra endpoints.
complete_sampling_pseudocode=
- Inputs: current state `x_i`, previous state `x_{i+1}`, current model derivative `epsilon_theta(x_i, i)`, positive consecutive step magnitudes `h_i` and `h_{i+1}`, and schedule factors `alpha_{i-1}`, `alpha_i`, `alpha_{i+1}`.
- Define the generic 2-step BELM recurrence:
- `x_{i-1} = a_{i,2} x_{i+1} + a_{i,1} x_i + b_{i,1} h_i epsilon_theta(x_i, i)`.
- Choose the O-BELM coefficients from local-truncation-error minimization:
- `a_{i,2} = (h_i^2 / h_{i+1}^2) * (alpha_{i-1} / alpha_{i+1})`.
- `a_{i,1} = ((h_{i+1}^2 - h_i^2) / h_{i+1}^2) * (alpha_{i-1} / alpha_i)`.
- `b_{i,1} = -(h_i + h_{i+1}) / h_{i+1} * alpha_{i-1}`.
- Update the state with:
- `x_{i-1} = a_{i,2} x_{i+1} + a_{i,1} x_i + b_{i,1} h_i epsilon_theta(x_i, i)`.
- For a VE-style sigma parameterization with `alpha = 1`, this simplifies to:
- `x_next = (h_cur^2 / h_prev^2) x_prev + (1 - h_cur^2 / h_prev^2) x_cur - h_cur (h_cur + h_prev) / h_prev * d_cur`.
- The paper's inverse update uses the same current derivative and the mirrored recurrence to recover `x_{i+1}` exactly, but that inversion half is optional for a forward-only localized probe here.
state_variables_and_history=Current state; immediately previous state; current derivative/noise prediction; current and previous step magnitudes; optional alpha ratios when the schedule is not VE-style.
nfe_accounting=Zero extra NFE. The 2-step O-BELM recurrence consumes only already-available states and the current model derivative.
